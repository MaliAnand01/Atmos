1. Global Identity & Design System
The VibeCheck Aesthetic
The brand identity is "Tactile Nightlife." Everything should feel soft to the touch but visually electric.

Typography
Display/Headings: Space Grotesk – Gives a geometric, modern, slightly techy vibe for event titles and big numbers.

Body/UI Text: Inter or Plus Jakarta Sans – Clean, highly readable for dates, locations, and descriptions.

Color Palette (Tailwind v4 @theme)
Background Void: Deep charcoal/blue-black (#0D0F14).

Clay Surface (Cards/Modals): Soft dark slate (#1A1D24).

Vibe Colors (Dynamic depending on the slider):

Chill Vibe: Bioluminescent Blue (#00F0FF) & Soft Indigo (#6366F1).

Energetic Vibe: Neon Pink (#FF007F) & Electric Orange (#FF5E00).

Text: Off-white (#F8FAFC) for primary, slate-gray (#94A3B8) for secondary.

Icons Library
Phosphor Icons: Choose the "Fill" or "Duotone" variants. Their rounded, soft geometry perfectly matches the inflated look of Claymorphism.

Dark Claymorphism CSS Architecture
In your Tailwind v4 setup, you will rely heavily on custom inner shadows to create the 3D "clay" effect.

The Clay Shadow: shadow-[inset_4px_4px_8px_rgba(255,255,255,0.05),_inset_-4px_-4px_8px_rgba(0,0,0,0.4),_8px_8px_16px_rgba(0,0,0,0.3)]

Border: Smooth rounding (rounded-3xl or rounded-full).

2. Animation Strategy (The "UI Flex")
Framer Motion (State & Layout Transitions)
Shared Layout Animations: When clicking an event card in the feed, use layoutId to seamlessly expand the card's image into the full-page hero banner.

Page Transitions: A soft fade-and-scale effect. The outgoing page scales down slightly and fades to opacity: 0, while the new page scales up from 0.95 to 1.0.

Micro-interactions: Buttons should have a whileTap={{ scale: 0.95 }} to enhance the squishy clay feel.

GSAP (Scroll & Physics)
The Vibe Slider: Use Draggable combined with InertiaPlugin so the user can "throw" the slider handle and it smoothly glides to a stop.

Horizontal Scroll: Use ScrollTrigger to pin the main container and translate the event cards along the X-axis as the user scrolls down with their mouse wheel.

Parallax Elements: Floating 3D shapes (spheres, rings) in the background that move at different speeds using ScrollTrigger.matchMedia for desktop.

3. Core Components & Layouts
The Floating Pill Navbar
Position: Fixed at the bottom center of the screen (mobile) or top center (desktop).

Design: A thick, rounded-full clay pill (bg-[#1A1D24]).

Interaction: Active links glow with a subtle neon drop-shadow matching the current "Vibe" color. When scrolling down, the pill shrinks slightly using Framer Motion.

Single Auth Modal (Login / Register)
Design: A large clay panel that floats over a blurred background.

Animation: Instead of separate pages, use a single Framer Motion AnimatePresence container. When switching from "Login" to "Register", the inner content slides out to the left, and the new form slides in from the right, while the container smoothly resizes its height.

4. Page Blueprints
Home Page
Dynamic Hero Section: A massive text headline ("Find Your Frequency"). The background is a dark, slow-moving canvas of colors. Right in the center is the massive, tactile Vibe Slider. As you drag it, the background colors morph (using GSAP to animate CSS variables).

Trending Orbits (The Horizontal Scroll): As you scroll past the hero, the page locks. You scroll horizontally through large, claymorphic event cards.

Featured Venues Grid: A bento-box style grid showing top locations, utilizing soft inner shadows.

Footer: A massive, dark clay slab at the bottom with a pulsing logo, quick links, and a newsletter signup input that looks like a debossed groove in the screen.

Single Event Detail Page
Header: Full-bleed image with a dark gradient overlay.

Sticky Ticket Bar: A floating clay panel on the right side (desktop) or bottom (mobile) that shows live remaining capacity and the "Book Now" button.

Lineup/Details: Staggered list items that fade in and slide up via Framer Motion as they enter the viewport.

5. Dashboard Workspaces (Role-Based)
To prove your Spring Boot backend handles roles correctly, the frontend will render entirely different dashboards based on the user type.

The Attendee (User) Dashboard
Identity: Personal, vibrant, focused on memories.

Upcoming RSVPs: A carousel of beautifully designed digital tickets (styled like boarding passes) with QR codes.

Vibe History: A chart or colorful timeline showing the types of events they've attended (e.g., "You've been 80% High-Energy this month!").

The Event Organizer Dashboard
Identity: Professional, data-heavy, but still utilizing the soft clay aesthetic so it doesn't look like a boring spreadsheet.

Live Capacity Tracker: A circular progress ring (animated with GSAP) showing real-time ticket sales driven by Spring Boot data.

Event Creator: A multi-step Framer Motion wizard to create an event, upload images, and set the "Energy Level" (1-10) for the algorithm.

The Super Admin Dashboard
Identity: Utilitarian, structural, commanding.

Global Metrics: Top-level stats (Total Users, Total Revenue, Active Venues) in debossed clay cards.

Moderation Queue: A list of newly submitted events pending approval, with satisfying swipe-to-approve gestures using Framer Motion's drag="x".
