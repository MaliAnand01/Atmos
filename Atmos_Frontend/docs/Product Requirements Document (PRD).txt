Product Requirements Document (PRD): VibeCheck1. Project OverviewVibeCheck is an interactive, atmosphere-first event discovery and booking platform. Unlike traditional ticket platforms that filter purely by date or location, VibeCheck allows users to discover events based on the desired "vibe" or energy level.Evaluation Objective: To demonstrate end-to-end full-stack proficiency by combining a robust, relational Java/Spring Boot backend with a highly interactive, animation-driven React frontend.2. Tech Stack ArchitectureFrontend: React.js, Tailwind CSSAnimation & Interactions: GSAP (ScrollTrigger, Draggable), Framer MotionBackend API: Java, Spring Boot (Spring Web, Spring Data JPA, Spring Security)Database: MySQL3. Core Features (MVP Scope)A. The "Vibe Slider" (Interactive Mood Search)Description: A custom, GSAP-powered drag slider ranging from 1 ("Deep Chill/Acoustic") to 10 ("High Energy/Club").Mechanism: As the user drags the slider, the React frontend debounces the input and sends dynamic GET requests to the Spring Boot API.Backend Logic: The Spring Boot API queries the MySQL database for events matching the specific "energy_level" integer, returning updated JSON payloads instantly.B. Immersive Event Discovery (Horizontal Scroll)Description: A visually striking event feed that scrolls horizontally rather than vertically.Mechanism: Built using GSAP's ScrollTrigger to translate vertical mouse scrolling into a horizontal layout shift.Data Handling: Paginated API calls to Spring Boot to ensure the frontend doesn't crash when loading high-resolution event images.C. Live Availability Booking EngineDescription: A seamless ticket reservation system.Mechanism: When a user clicks "Book," Framer Motion handles the smooth page transition to the checkout modal.Backend Logic: Spring Boot handles the transactional logic. It checks MySQL for available_capacity, decrements the ticket count, and generates a booking record linked to the User ID.D. User Authentication & DashboardDescription: Secure login and a profile page displaying upcoming RSVPs.Backend Logic: Spring Security handles password hashing and session management (or JWT tokens).4.
